# Cartella Immagini

Metti qui i tuoi file immagine. Saranno accessibili direttamente come URL nel sito.

## Immagini usate nel sito:

- `alan.jpg` → La tua foto profilo (usata nella sezione "Chi Sono").
  Riferimento nel codice: `src="/images/alan.jpg"`

## Come aggiungere le immagini per i progetti:

Crea un file come `ortix.jpg`, `tothemooon.jpg`, ecc. poi vai in
`src/components/sections/ProjectsSection.tsx` e decommenta la riga `<img>` nei placeholder.

Formato consigliato: **JPG o WebP**, risoluzione minima **800x600px**.
